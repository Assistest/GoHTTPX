## 发布约束

在原有 112 项 Python 回归基础上增加 3 项发布验证，未放宽业务测试预期：拒绝错误/缺失的二进制 revision、dirty 标记及平台，实际执行 EXE 检查版本，并拒绝从未提交源码生成正式发布说明。

源码提交后重新构建正式产物，独立 EXE 和 wheel 内置 EXE 都必须通过 `tools/release.py notes` 检查；校验结果、提交 revision、文件大小与 SHA-256 写入 GitHub Release。GitHub Actions 还会重新执行完整回归和独立安装测试，通过后才使用已有 PyPI Trusted Publisher 上传。

安装包仅支持 Windows amd64、Python 3.10+；Linux/macOS 自动托管尚不支持。本次没有新增全天内存压测结论。
